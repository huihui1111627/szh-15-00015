# 隧道掘进施工剖面与风险联动引擎

将刀盘扭矩、推进速度、土仓压力、注浆量与地层变化组合为**可操作施工剖面**，
沿线路选择预测区段、调整下一阶段掘进参数，并随推进逐环更新
**地表沉降、刀具磨损、涌水风险**；地层突变或多参数共同越界时保留异常前后
状态并给出连锁原因链；支持从历史稳定节点分叉多方案同步推演，覆盖传感数据
迟到、人工指令与自动保护同窗冲突、服务重启状态接续等工程场景。

## 运行

```bash
python3 demo.py                 # 端到端中文演示（无需第三方依赖，Python 3.9+）
python3 -m unittest discover -s tests   # 11 项测试
```

## 设计要点

- **事件溯源**：每个施工方案一条仅追加 JSONL 日志（`data/events/<会话>/<方案>.jsonl`），
  写入走临时文件 + `os.replace` 原子提交；实时处理与重启重放共用同一套 `_apply_event`。
- **施工剖面 `ConstructionProfile`**：预测区段的目标设定（扭矩/速度/土仓压力/注浆量）
  加安全硬包络；`preview_segment()` 在不下发现场的情况下试算候选剖面风险，
  `adjust_next_stage()` 更新下一阶段参数。
- **随推进更新的风险 `risk.py`**：纯函数、确定性、可替换为真实模型。
  - 地表沉降：体积损失率（欠压/欠注浆/超速/软弱地层叠加）经 Peck 槽谷公式换算；
  - 刀具磨损：地层磨蚀性 × 扭矩负荷 × 环长逐环累计；
  - 涌水风险：渗透性 × 土仓压力相对水头的驱动压差。
- **异常判定**：地层突变即异常；否则需 ≥2 项参数同时越过硬包络；
  严重异常（突变叠加越界、高涌水+低压、沉降超限等）触发自动保护。
  异常事件内保留 `before_snapshot` / `after_snapshot`（剖面、读数、风险、地层、
  保护状态）以及按「地层 → 参数越界 → 风险后果」排序的连锁原因链。
- **迟到/重复/跳环数据**：以读数事件时间与方案水位线比较判迟到；
  容忍窗口（默认 30 min）内按事件时间追溯重算，异常标记 `retroactive`
  并可能修订/消解既有异常；超窗与重复读数隔离留痕（`quarantined`）；跳环读数
  隔离等待补齐。
- **指令仲裁**：人工 / 自动保护 / 自动优化指令先入未决队列，关环（或自动保护
  触发）时同窗仲裁——紧急停机最高优先，停机锁定只允许复位/复工，保护指令
  阻断削弱保护的人工指令，全部决策与拒绝原因记入 `commands_resolved`。
- **多方案同步推进**：仅允许从**历史稳定节点**（连续 N 环无异常）
  `fork_from_stable_node()` 复制出 `whatif` 方案，传感读数扇出到全部方案、
  落后方案以主控已记录读数补齐；`whatif` 指令标记 `simulated` 不下发现场，
  只更新自身剖面与风险；`promote_scenario()` 可将方案提升为主控（原主控降级）。
- **重启接续**：`TunnelService.restart()` 重放事件日志，恢复各方案环号、风险、
  异常、隔离记录、稳定节点、分叉关系，以及**未执行的未决指令**
  （`command_submitted`），下一关环窗口继续仲裁。

## 模块结构

- `tunnel/models.py`：剖面、地层、读数、风险、异常/快照、稳定节点等领域模型；
- `tunnel/risk.py`：沉降/磨损/涌水推演、越界判定、异常分级（纯函数）；
- `tunnel/store.py`：事件日志与地层文件的原子读写；
- `tunnel/service.py`：推进、迟到处理、仲裁、分叉/提升、重启重放等业务流程；
- `demo.py`：完整场景演示；`tests/`：单元测试。
